# 投稿管理表の説明

投稿は `posts.csv` で管理します。1投稿につき1行です。

## 列の説明

| 列名 | 内容 | 例 |
|---|---|---|
| id | 通し番号（T001から） | T001 |
| 投稿日 | 投稿した日（YYYY-MM-DD） | 2026-11-25 |
| 種類 | 通常／スレッド（連投）／返信／再投稿 | 通常 |
| テーマ | 投稿の話題 | 育児グッズ紹介 |
| 関連商品id | `kona-papa-room` の products.csv の id（なければ空欄） | P003 |
| 本文の要点 | 投稿内容の要約 | ピアノジムの使用感 |
| 画像 | 画像を付けたか（あり／なし／未確認） | あり |
| リンク先 | ROOM／ブログ／Instagram／なし／未確認 | ROOM |
| いいね | 確認時点の数 | 12 |
| 返信 | 確認時点の数 | 2 |
| 再投稿 | 確認時点の数 | 0 |
| 確認日 | 反応の数を確認した日 | 2026-11-26 |
| メモ | 気づき | |

## ルール

- 分からない項目は「未確認」と書く
- 本文の全文を残したい場合は、今後 `posts/texts/` フォルダを作って保存する
