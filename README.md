投稿内容、反応、フォロワー数、運営方針、改善履歴を記録します。

## フォルダ構成

```
.
├── README.md              … このファイル。運営概要と使い方
├── CLAUDE.md              … AIセッション向けの引き継ぎガイド
├── policy/
│   └── operation-policy.md … 運営方針
├── posts/
│   ├── README.md          … 投稿一覧の列の説明
│   └── posts.csv          … 投稿の管理表
└── progress/
    ├── README.md          … 進捗記録の書き方
    ├── status.md          … 最新の状況（毎回ここを更新）
    ├── metrics.csv        … フォロワー数などの推移
    ├── log.md             … 実績・改善履歴（日付順）
    └── todo.md            … 今後やること
```

## 更新の流れ

1. 投稿したら `posts/posts.csv` に1行追加する
2. フォロワー数などを確認したら `progress/metrics.csv` に1行追加する
3. やったこと・気づいたことは `progress/log.md` に追記する
4. 最後に `progress/status.md` の最新状況を書き換える

## 記録のルール

- 分からない情報は推測で埋めず「未確認」と書く
- 個人情報（本名、住所、家族の個人を特定できる情報など）は保存しない
- 認証情報（パスワード、APIキー、ログイン情報など）は保存しない
- 楽天ROOMの記録は `kona-papa-room` リポジトリで管理する
